\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
Finding the right engineering expert for a task is still slow and mostly
manual. General freelance marketplaces use keyword search and free browsing.
This leaves clients to weigh skills, availability, cost, location, and
reputation by hand. This pre-thesis presents the design of a
\textit{digital marketplace platform for engineering services} that closes
this gap with an \textit{intelligent multi-criteria matching mechanism}. The
mechanism ranks providers with a weighted scoring model over five factors:
skill compatibility, availability, cost range, location proximity, and user
rating.

The platform is built from two engineering views. From a \textit{software
engineering} view, it uses a modular, three-layer client-server architecture
that clearly separates presentation, business logic, and data access, backed
by systematic testing. From a \textit{network engineering} view, it focuses
on secure communication over HTTPS, role-based access control, and an
evaluation method based on latency and response-time analysis under different
loads.

This report covers the problem, a review of related work on online service
marketplaces and multi-criteria decision making, the methodology for the
matching algorithm, and the system design of the working prototype. It ends
with a clear work plan for the remaining thesis phases, including the full
build and evaluation of the matching engine.
